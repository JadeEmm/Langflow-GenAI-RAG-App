# Langflow-GenAI-RAG-App
In this Generative AI project I:
- Created an end-to-end GenAI app with Langflow
- Implemented retrieval-augmented generation (RAG)
- Integrated with Microsoft Azure OpenAI embedding and foundation models
- Spun up a vector database on DataStax Astra DB
